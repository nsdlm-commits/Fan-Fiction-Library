# 贤内助谁爱当谁当-3

和附中同学张艺上个月借着共演剧目收官的理由吃了个饭，估计又有多久见不到了，王浩楠喝酒一急就先上脸后上头，酒后的酣红弥漫上他胸口以上的所有皮肤，双手撑着头直言有点想存贤，光明磊落没一点害羞。张艺把酒给他满上，说想了就去看呗，探个班，存贤肯定欢迎啊。

“我去年去过一回，待了三天总共见了两面就走了，不想再麻烦他了，反正也能打视频，他回来也能见到。”

王浩楠对李存贤如此浩荡的依恋让张艺大为震撼，想起来这一对情侣小时候毛都没长齐的样子，喝了酒嘴巴碎起来没几句李存贤好话，末了又说他确实忙，不过我估计吧，你去看他他也能挺高兴。

“我就是觉着有点没必要，都谈这么久了多腻歪。”

张艺开始引导性发言，想到李存贤那档子事儿劝王浩楠还是要和李存贤多见见，王浩楠显然是没懂他的言外之意。


“我意思是，你俩就算开放式关系也不能就靠一年见那几面……”

“我们不是开放式……确实没聊过这个，但是不是啊，我谈恋爱很专一的。”


张艺意识到自己似乎说错了话，老同学不常见面也没熟到无话不谈的地步，况且他也只是从坊间流传里大致推测，搪塞了几句打哈哈混了过去，王浩楠有点醉，张艺问你是去李存贤那豪宅还是回你租的地方，王浩楠把整个人挂在张艺身上，含含糊糊打了个酒嗝说回我那里，张艺打了个车把他送到家又看着他上楼进家门才放心，一出单元门就给李存贤发微信，问他你和王浩楠到底什么情况。

李存贤没回，张艺有点迷惑，他这个共友做得有些为难。等李存贤看到消息回复之后已经是第二天，李存贤一开始还跟他装傻，说你跟王浩楠见得比我跟他都频，嫉妒，张艺骂了他两句之后李存贤也不装了，说我也没做什么坏事吧，我就是不想让他多想。

“你跟他比那可坏没边儿了……那你以前的事他都知道？”

“知道知道，我们那会儿也没谈，我早跟他说过了”

“那你现在的呢？”

 


李存贤搞不懂是哪个环节出了问题，其实也没出问题，他给自己定的规矩是除了副导带着玩的局以外，不管是剧组夫妻还是别的，一个人最多三个月，走肾不走心，嘴严的最好，时间一到立刻断掉，微信抖音全拉黑，不给自己添麻烦也不给别人找麻烦，他对外是单身不好推脱，王浩楠的事情除了团队里的没人知道，心里默念玩得开也是为了保护王浩楠。

这种话念得多了成了一种催眠，李存贤好像打心底里觉得这种事情不算道德败坏，顶多算风流...解决生理问题，有了需要得发泄出去，全憋身体里该憋坏了。贤少风流倜傥做鬼也销魂，这也不意味着王浩楠在他心里无足轻重，底层代码里的劣根性作祟让他正大光明地小偷小摸给自己找刺激，见到王浩楠又摒弃掉否认掉了那个不能被他发现的自己。

这么久王浩楠真的一点都没发现吗？李存贤觉得王浩楠多少也是知道一点，刷刷娱乐新闻就该睁一只眼闭一只眼，自己是什么人王浩楠也早该清楚。从小到大自己的事情他都知道，复合的时候把之前搞男团时期发生过的事情和盘托出过一次，王浩楠问了几句，那网上说的都是真的吗？李存贤当时和他在私人影院，他让王浩楠正面跨上他的大腿坐他怀里，左手伸他衣服里摸胸右手掌握住他后颈，受害者仪态一边卖惨一边嘴唇贴着嘴唇跟他道歉。不过交代罪行也只有那一次，李存贤后来没捅出过娄子也没犯过大错，他猜王浩楠能宽容到纵容他，然后纵容一次拉低底线之后就可以纵容很多次，他也猜王浩楠能够理解他的苦衷，说实话他不信他不在王浩楠身边的时候王浩楠面对一群花枝招展的演员同事能清心寡欲，谁还不是男人了，他都不管王浩楠。李存贤又想，王浩楠就算知道了之后对他生气，他笃定自己也有足够的理由和能耐把他哄好，王浩楠这种渴爱批太好哄了，亲一亲抱一抱给点承诺就自己咬回钩上。

早知道不跟张艺说那么多了，他都忘了什么时候和张艺说的这话。自己一喝酒就爱吹牛逼的坏习惯还是要改一改，确实想不起来喝多了跟多少人讲过，常在河边走哪有不湿鞋，心里有一丝忐忑，但更多的被一种无所谓的情绪压了下去，等他彻底杀青也要到一个月之后，这段时间王浩楠要是不来问他估计也不会有什么事情，自己吓自己，呼。
